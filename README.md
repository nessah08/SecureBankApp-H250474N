# Secure Banking Application

## Description

This project is a console-based banking application developed in Java.
It allows users to securely log in, manage bank accounts, and perform
basic banking transactions while applying secure coding and OOP principles.

## Features

- User authentication and login
- Create a new bank account
- View account balance
- Deposit funds
- Withdraw funds
- Store user credentials in text files
- Store account details in text files
- Store transaction history in text files
- Load saved data when the application starts
